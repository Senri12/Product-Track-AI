# Product Track AI - Визуализация данных

React-приложение для визуализации и анализа данных экспериментов с языковыми моделями.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется на `http://localhost:3333`

### Сборка для продакшена

```bash
npm run build
```

## 📊 Возможности

- **Фильтрация данных** по версиям, моделям, промптам, лекциям и источникам
- **Интерактивные графики** с использованием Recharts
- **Сравнение метрик** между версиями, моделями и лекциями
- **Статистика** с расчетом средних, минимумов и максимумов
- **Таблица данных** с сортировкой и пагинацией
- **Адаптивный дизайн** для разных размеров экрана

## 📁 Структура проекта

```
visualization/
├── src/
│   ├── components/      # React компоненты
│   │   ├── Filters.tsx   # Компонент фильтров
│   │   ├── Charts.tsx    # Графики
│   │   ├── Comparison.tsx # Сравнение метрик
│   │   ├── Statistics.tsx # Статистика
│   │   └── DataTable.tsx # Таблица данных
│   ├── App.tsx           # Главный компонент
│   ├── types.ts          # TypeScript типы
│   └── main.tsx          # Точка входа
├── public/
│   └── all_data.csv      # Данные для визуализации
└── package.json
```

## 📝 Использование

1. Поместите файл `all_data.csv` в папку `public/`
2. Запустите приложение: `npm run dev`
3. Используйте фильтры для анализа нужных данных
4. Изучайте графики и сравнения

## 🛠 Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик
- **Recharts** - графики
- **PapaParse** - парсинг CSV
- **Lucide React** - иконки

## 📊 Метрики

Приложение визуализирует следующие метрики:

- **F1 Score** - баланс точности и полноты
- **Precision** - точность
- **Recall** - полнота
- **Hallucination** - галлюцинации
- **Faithfulness** - следование контексту
- **Claim Recall** - полнота извлечения
- **Context Precision** - точность извлечения
- **Context Utilization** - использование контекста
